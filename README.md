# Portfólio JuanIan7

Site do portfólio de serviços (sites, sistemas e planilhas sob medida), feito para o GitHub Pages no domínio `juanian7.systems`.

- `index.html`: portfólio, previsão de valores e formulário de pedido.
- `comecar/`: primeiros passos do cliente (vídeos do GitHub e da Hostinger, com legenda).
- `privacidade/`: política de privacidade do site e do aplicativo de uso privado Hermes Claudia.
- `claudia/`: página inicial do aplicativo Hermes Claudia (exigida pelo Google para tirar o app do modo de teste).
- `assets/config.js`: liga o formulário (endereço do Apps Script). Vazio = modo de prévia, nada é enviado.

Sem etapa de build: HTML, CSS e JavaScript puros. Para ver no Mac: `python3 -m http.server 4173` nesta pasta e abrir `http://localhost:4173`.

Regra: mostrar a prévia ao Juan antes de publicar. Não colocar e-mail, telefone, senha ou chave em nenhum arquivo (o repositório é público).
